## Default Permission

La Live Activity du repos : démarrer, suivre et terminer le chrono
affiché sur l'écran verrouillé et le Dynamic Island.

#### This default permission set includes the following:

- `allow-start-activity`
- `allow-update-activity`
- `allow-end-activity`
